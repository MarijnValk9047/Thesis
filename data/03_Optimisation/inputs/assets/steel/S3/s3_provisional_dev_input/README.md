# S3 Provisional Development Input

This directory is reserved for future provisional `S3` development inputs after the `S3.0a` schema and review policy are accepted.

It intentionally contains no executable coefficient table in `S3.0a`.

Future rows must remain provisional, reviewed, and non-thesis until explicitly promoted.

## S3.0b WAG Development-Only Packet

`s3_wag_selected_dev_inputs.csv` is a provisional development-only packet for the `S3.0b-b` WAG scaffold.

Rows in that file are not approved model inputs and not thesis-grade inputs. Rows marked `currently_loaded=true` are supported only by the governed `S3.0b-b1` WAG diagnostic scaffold loader; that loader is not an approved thesis-input loader and does not make a full plant diagnostic runtime-ready while mandatory activity and demand profiles remain absent.

The companion selection review remains in `../s3_candidate_review/s3_wag_dev_input_selection_review.csv`. It is a review surface and must not be used as a loader input.

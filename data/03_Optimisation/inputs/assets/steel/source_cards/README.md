# Steel Source Cards

## Purpose

Source cards are compact structured records for stable sources that may later support steel parameter promotion.

They are the controlled bridge between raw source material and candidate or approved parameter tables.

## Required Principle

A source card must use a stable source reference.

Acceptable anchors include:

- a stable public URL;
- a report title and year;
- a controlled local file path for a stored source document;
- a stable repository file reference for an internal note that is intentionally versioned.

## Not Allowed As Stable Source References

Do not use:

- internal Deepsearch turn citations;
- chat-local citation markers;
- copied unstable export references;
- untracked screenshots without source context.

If a research memo suggests a useful parameter category, first find the stable underlying source before creating a formal source card.

## Minimum Use Rule

Each source card should make it clear:

- what the source supports;
- what it does not support;
- whether model use is allowed;
- which parameter categories or validation targets it can inform;
- what limitations remain visible.

# Final Aligned DAM Export Method Note

## Scope

This note documents the final aligned DAM export setup for downstream optimisation inputs:

- D-only hourly forecasts;
- D-only quarter-hour forecasts;
- D+4 hourly setup;
- D+4 quarter-hour setup.

D+6 is intentionally excluded.

## Hourly Anchor

The D-only hourly level anchor is the repaired LEAR Strict D-only 1092 artifact:

`data/02_Forecasting/01_DA_prices/hourly_da/repair_runs/20260522_210021_lear_strict_donly_support_repair/hourly_lear_strict_donly_1092_full_support_anchor.csv`

This artifact is used as a production forecast source. Export row support is not inner-joined to actuals.

## Quarter-Hour Construction

The quarter-hour construction reuses the existing repository method based on hourly level plus intra-hour/canonical deviations:

`qh_price = hourly_anchor_price + qh_deviation`

The deviation layer comes from the frozen canonical quarter-hour path:

`data/02_Forecasting/01_DA_prices/quarterhour_da/frozen_actual_paths/canonical_v1/synthetic_actual_15min_canonical.csv`

That canonical path was generated by `quarterhour_da.canonical_actual` from observed hourly actuals and the observed quarter-hour shape library. Its manifest records that forecast outputs, optimisation outputs, and economic results were not used to build it.

The implementation reuses the canonical intra-hour deviation columns and applies an additional per-hour zero-mean correction before adding them to the hourly forecast anchor. Therefore, for every exported hour:

`mean(qh_price for the four quarters in hour h) = hourly_anchor_price_h`

within numerical tolerance.

This is not naive interpolation, linear spreading, random noise, direct 15-minute LEAR, or the observed-QH XGBoost FS2 backbone.

## Canonical / Counterfactual Status

Quarter-hour forecasts for the 2024-10-01 to 2025-09-30 hourly test year occur before native 15-minute observed-market truth is available for that full period. These rows are labelled as synthetic/counterfactual production forecasts for downstream experiments, not observed-market scoring truth.

The frozen canonical path retains the local DST days 2024-10-27 and 2025-03-30. The final aligned exports use the hourly thesis 24h-only delivery-day policy, so those two delivery dates are explicitly statused and excluded from D-only production exports.

## D+4 Status

The existing D+4 candidate is the strict-no-future 1092 LEAR artifact under:

`data/02_Forecasting/01_DA_prices/hourly_da/runs_lago_lear/20260508_122730_lago_lear_six_year_benchmark/`

It includes known-at audit files and checkpoint/progress metadata. Because previous full D+4 runtime was about 5.5 hours, the final export runner inspects this artifact and creates controlled commands for regeneration instead of launching a long D+4 run automatically.

## Scenario Rule

Where scenarios are generated, the final setup must use exactly 30 final scenarios per forecast origin and granularity. Existing scripts with different defaults must be called with explicit `--n-final 30`, and quarter-hour scenario scripts must not be left at their older 15-final-scenario default.

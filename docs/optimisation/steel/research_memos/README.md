# Steel Research Memos

## Purpose

This folder holds working research memos used to shape category discovery, schema design, and follow-up research tasks for the steel workstream.

These memos are not approved source evidence and must not be treated as thesis-grade parameter support by themselves.

## Source-Status Rule

Research memos may contain:

- exploratory summaries;
- provisional categorisations;
- unstable exported citations;
- conversation-local references from external tools.

That material is useful for finding candidate parameter families and missing research waves, but it is not a stable evidence base for approved model inputs.

## Required Promotion Path

Do not promote a memo statement directly into an approved model input table.

Use this path instead:

1. research memo identifies a candidate category or question;
2. stable public source or controlled local file is found;
3. a source card is created from that stable source;
4. the candidate enters the steel parameter universe or candidate register;
5. approved model input tables are created only after review.

## Citation Rule

Internal citations inside Deepsearch or similar exports may be unstable. Do not copy those internal turn citations into:

- source cards;
- approved parameter tables;
- thesis evidence notes.

Use stable references instead, such as:

- a stable public URL;
- a report title plus year;
- a controlled local file path for a stored report or memo.
